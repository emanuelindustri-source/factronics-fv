## Reglas de uso

1. Este glosario es una **propuesta de vocabulario**, no contenido técnico validado.
   No se usa para publicar procedimientos, números de parte, códigos de error ni
   especificaciones.
2. Una traducción solo pasa a **“aprobada”** cuando Khristyan Hidalgo la aprueba por
   escrito (commit, issue o documento firmado). Hasta entonces, cualquier uso en
   contenido real queda bloqueado.
3. No se reproduce contenido de `VIDEOJET_DOCS_ENTRADA/` (carpeta local, gitignored).
   El vocabulario es genérico del dominio y se contrastó **solo con el inventario
   local** (`01_CIJ/INVENTARIO_1880C.md`), sin copiar textos, códigos ni listas de partes.
4. Los términos de marca o de siglas internacionales (`CIJ`, `TTO`, `make-up`,
   `Material You`, `Videojet`) se conservan o se explican; no se traducen como si fueran
   genéricos.
5. Las variantes PT-BR y PT-PT se mantienen separadas a propósito (vocabulario distinto
   para “configurações/definições”, “peça/referência”, etc.).

## Términos que NO se traducen (marcas y siglas)

- **F&V**, **Factronics, C.A.**, **Videojet Technologies** (nombres propios).
- **Material You**, **Android**, **IndexedDB**, **i18next**, **Jetpack Compose** (tecnologías).
- **CIJ** y **TTO** se pueden explicar entre paréntesis, pero la sigla se conserva.
- **make-up** se conserva entre paréntesis porque el equipo suele usar el término inglés;
  la propuesta en cada idioma aparece en la tabla.
